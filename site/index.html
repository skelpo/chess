Install

The same engine and online server everywhere: Claude Code and opencode get a graphical board, Codex plays in the chat, and the terminal game runs anywhere.

Claude Code

  1. In Claude Code (2.1.316 or later), run /plugin install chess --marketplace skelpo/chess.
    On older versions: /plugin marketplace add skelpo/chess, then /plugin install chess@skelpo-chess.
  2. Type /chess. The board opens in a pane.
  3. Optional, for the Perry-native engine: npm install -g tuichess. The plugin uses it when it's on your PATH.
  4. For the board beside the chat instead of below it, switch Claude Code to its fullscreen layout: /tui fullscreen. There you can also click the board.

Update later with /plugin marketplace update skelpo-chess and /plugin update chess@skelpo-chess.

opencode

The graphical board (opencode 2.0.20 or later):

mkdir -p ~/.config/opencode/plugins/tuichess
curl -fsSL https://codeload.github.com/skelpo/chess/tar.gz/main | tar -xz -C ~/.config/opencode/plugins/tuichess --strip-components=3 chess-main/opencode/plugin
opencode reload

  • Type /chess in opencode. Play with the arrows and Enter, or type e2e4.
  • u undoes, i gives a hint, t flips the board, +/- change the level, m opens the menu, Esc goes back to the chat.
  • The session sidebar shows the position while you chat, and the agent sees the same game through its chess_board tool. Ask it how your position looks.
  • Online: press o on the board (or type /chess-online) and pick a username. In the lobby, p plays anyone and y/x answer challenges. It's the same username as the terminal game. The board shows both clocks. In online games the agent can read the position and the clocks, but gives no hints and makes no moves.

Optional, a text board in the chat as well (/board-plain, played by the agent through the engine's tools):

opencode mcp add chess --global -- npx -y tuichess mcp
mkdir -p ~/.config/opencode/commands
curl -fsSL https://raw.githubusercontent.com/skelpo/chess/main/opencode/commands/board-plain.md -o ~/.config/opencode/commands/board-plain.md
opencode reload

Codex

codex plugin marketplace add skelpo/chess
codex plugin add chess@skelpo-chess

Start a new Codex session and say "let's play chess, I'm white, level 3", then give your moves ("e4", "knight to f3"). Codex shows the board in the chat after every move, and you can ask for a hint, a takeback or another level. Codex has no panes for plugins, so it's a text board. For the graphical board and online play next to Codex, run npx tuichess in another terminal.

Any terminal

npm install -g tuichess

Then tuichess (or without installing: npx tuichess). Arrows and Space move, or type e2e4; help lists every command. Type online (or start with tuichess --online), pick a username, then play or challenge <name>. Native on macOS (Apple silicon and Intel) and Linux; on Windows, use WSL for now.

Docs

Playing

Type moves as coordinates (e2e4, e7e8q) in the pane's move field, or use its menu: New game, Undo, Hint, Flip, Easier, Harder, Engine, Play online. ctrl+x tab gives the pane the keyboard, Tab walks the menu, Esc returns to the prompt. You can also play from the prompt: /chess e2e4, /chess undo, /chess hint.

Claude plays along

Claude sees the same game through its tools, so you can ask "what should I play here?", "why was that a mistake?", or have it move for you. Its tools: chess_new_game, chess_move, chess_show, chess_legal_moves, chess_hint, chess_engine_move, chess_undo, chess_claim_draw, chess_settings. During an online game Claude stays out of it.

Online

  • Play online in the menu (or online in the move field). Pick a username: 3 to 20 letters, digits, _ or -, first come, first served. No password or email: the plugin keeps a random token for the name on your computer.
  • Play anyone pairs you with the next waiting player; whoever waited longer plays White. Or Challenge someone from the online list; they can Accept or Decline.
  • Clocks: 10 minutes per player plus 5 seconds per move. Running out of time loses; it's a draw if the opponent has only a king, or a king and one bishop or knight. No chat. Someone gone from a game for 10 minutes loses it. No takebacks or hints online.
  • The high scores rank wins, then fewer losses, then more draws. Games shorter than 10 half-moves don't count.

The engine

The engine is plain TypeScript with no dependencies. The terminal game (npm install -g tuichess) is a native executable compiled by Perry. With it installed, the Claude Code plugin runs every engine move and hint as a fresh native process outside Claude Code (it starts in about 10 ms); without it, the plugin uses the same engine as built-in JavaScript, and the board says which one played. The online server is the same: one TypeScript file, compiled by Perry, running here.

Other agents (MCP)

The same tools are available to opencode, Cursor and any other MCP client as a local stdio server, either from source or from the native binary:

node mcp/src/server.ts            # Node 22.18+
chess-engine-<os>-<arch> mcp      # Perry native, no Node

API

The online server is https://api.tuichess.dev: HTTP and JSON with long polling. Authenticated calls send Authorization: Bearer <token>.

EndpointPurpose
POST /v1/registerBody {"name"}. Claims a username, returns {"name", "token"}.
GET /v1/state?since=<n>Everything one player sees: online players, challenges, the game, the high scores. Held up to 25 s until something changes.
POST /v1/actionqueue, unqueue, challenge / accept / decline with name, cancel, move with uci, resign, draw, leave.
GET /v1/leaderboardThe high scores. No token needed.
GET /healthok
